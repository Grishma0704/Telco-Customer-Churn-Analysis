# Predictive Retention Strategy: Telco Customer Churn Optimization

## Project Overview:
This project focuses on identifying high-risk customer segments for a telecommunications provider to reduce annual turnover. By leveraging Machine Learning and Exploratory Data Analysis (EDA), I developed a predictive model to identify churn drivers and formulated data-driven retention strategies.

 ## Key Results:
 * **Model Performance**: Achieved 82% accuracy using Random Forest and Logistic Regression models via Scikit-Learn.
 * **Data Engineering**: Preprocessed 7,000+ records using SQL and Python (Pandas) to handle missing values and encode 16 categorical variables.
 * **Business Insight**: Identified a critical 42% attrition rate in monthly contracts through a custom Power BI dashboard.
 * **Impact**: Proposed retention strategies aimed at reducing annual customer turnover by 15-20%.
 
## Tech Stack:
* **Languages**: Python (Pandas, NumPy, Scikit-Learn), SQL 
* **Visualization**: Power BI 
* **Environment**: Jupyter Notebook / VS Code 

## Evaluation Metrics:
* To ensure the reliability of the churn predictions, the model was evaluated using:
        * **Accuracy**: 82% 
        * **Classification Metrics**: Precision, Recall, and F1-Score to balance the detection of churners vs. non-churners.
